# JSON Annotation Samples

This repository contains sample JSON annotation and document extraction QA work.

The examples demonstrate review tasks commonly used in KYC-style annotation workflows, including:

- JSON validation
- Nested schema review
- OCR extraction validation
- Data quality checks
- Document review
- Error flagging

## Files

- `kyc_annotation_errors_sample.json` shows dummy extracted KYC data with QA findings and flagged annotation errors.
- `kyc_annotation_corrected_sample.json` shows the same dummy record after correction and validation.

All data in this repository is dummy/sample data only. It does not contain real personal, financial, or identity information.
